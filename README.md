markdown# FIIL.kr — 제주 스마트 민원 대응 시스템

> 시민이 촬영한 사진 한 장으로 제주의 환경 문제를 AI가 분석하고 즉시 대응합니다.

---

## 📌 프로젝트 소개

**FIIL**은 제주 시민이 스마트폰으로 환경·공공 문제를 촬영해 전송하면, 멀티 AI 엔진이 자동으로 분석·분류하고 담당 자원을 배정해 신속하게 대응하는 스마트 민원 플랫폼입니다.

모든 조치 내역은 **Openhash Network** 블록체인에 위변조 불가능하게 영구 기록되어 행정 투명성을 보장합니다.

---

## ✨ 주요 기능

### 5단계 스마트 대응 프로세스

| 단계 | 내용 |
|------|------|
| 1️⃣ 시민 촬영 | 스마트폰으로 문제 상황을 촬영하고 전송 |
| 2️⃣ AI 이미지 분석 | Claude · Gemini · DeepSeek 멀티모달 AI가 상황 분류 및 대응책 수립 |
| 3️⃣ 자원 자동 배정 | 장비·인원·차량을 자동 배정하여 출동 지시 |
| 4️⃣ 이행 모니터링 | 실시간 조치 진행 상황 추적 및 완료 확인 |
| 5️⃣ 블록체인 기록 | Openhash Network에 모든 내역 영구 보존 |

### 서비스 현황

- 📊 누적 신고 건수: **2,847건**
- ⚡ 48시간 이내 처리율: **96.2%**
- 🤖 AI 대응 시나리오 유형: **7종**
- 🔗 블록체인 기록 보존: **영구**
